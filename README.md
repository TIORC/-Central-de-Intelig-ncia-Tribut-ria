# Lumina Tributária

Crie a base de um sistema web chamado Central de Inteligência Tributária.

O sistema será usado futuramente para criação de apresentações profissionais para clientes, com base em dados tributários, financeiros e empresariais.

Neste momento, crie apenas a estrutura visual e funcional básica, sem implementar IA, leitura automática de arquivos, geração automática de slides ou recursos avançados.

Visual

Utilizar identidade visual corporativa e moderna:

Azul-marinho como cor principal

Amarelo/dourado como cor de destaque

Branco como fundo principal

Visual minimalista

Layout limpo

Tipografia moderna

Cards discretos

Bordas suaves

Interface premium e profissional

Evitar excesso de elementos, cores ou efeitos.

Importante

Nesta primeira versão:

não integrar IA;

não integrar APIs;

não criar backend complexo;

não implementar leitura de Excel, Word ou PDF;

não implementar geração automática de PowerPoint;

não criar lógica tributária;

não criar automações;

não criar recursos desnecessários.

O objetivo é construir somente uma base sólida, organizada e visualmente profissional, preparada para receber novas funcionalidades posteriormente.

Manter código modular e componentes reutilizáveis para facilitar futuras expansões.
